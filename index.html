Descomposición primaria

Estructura de Lazard (G_i, H_i), Lema de Hensel (factores de cualquier grado) y componentes primarias.

Algoritmo-3 — Descomposición primaria (PD)
  1. Input: (f0,…,fk) base de Gröbner, P·Gk+1=1
  2. Output: base de la componente primaria en m
  3. // Fase 1: ideales maximales
  4. for i = 1,…,k do
  5. factorizar Gi en k[x]: Gi = ∏ uijmij
  6. for cada factor uij do
  7. vij ← Hi mód uij en (k[x]/⟨uij⟩)[y]
  8. factorizar vij; cada factor v da m = ⟨uij, v⟩
  9. // Fase 2: componente primaria en m = ⟨u,v⟩
  10. m ← multu(f0);  f0 ← u(x)m
  11. n ← multv(Hk mód u)
  12. Hk ≡ vn·w (mód u),  w ≠ 0
  13. (s,t) ← HenselLift(Hk, vn, w, um)
  14. Hk ← s
  15. // Fase 3: simplificar los Gi
  16. return GroebnerBasis(f0,…,fk)

Algoritmo de división

Divide un dividendo (concreto o genérico de grado n) por una lista de divisores. El resto depende del orden de los divisores.

Algoritmo-1 — División polinomial
  1. Input: f1, …, fs, f
  2. Output: q1, …, qs, r
  3. qi := 0;  r := 0;  p := f
  4. while p ≠ 0 do
  5. i := 1;  div := false
  6. while i ≤ s and div = false do
  7. if LT(fi) | LT(p) then
  8. qi := qi + LT(p)/LT(fi)
  9. p := p − (LT(p)/LT(fi))·fi
  10. div := true
  11. else i := i + 1
  12. if div = false then
  13. r := r + LT(p);  p := p − LT(p)
  14. return q1, …, qs, r

Algoritmo de Buchberger

Calcula la base de Gröbner reducida (única) del ideal generado.

Algoritmo-2 — Buchberger
  1. Input: F una base de I
  2. Output: G base de Gröbner de I
  3. G := F
  4. repeat
  5. H := G
  6. for todo par p ≤ q en H do
  7. if resto(S(p,q), H) ≠ 0 then
  8. G := G ∪ { resto(S(p,q), H) }
  9. until H = G
  10. return G
